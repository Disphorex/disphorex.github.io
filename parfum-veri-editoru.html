← Admin ana sayfası

Ürün kimlikleri ve metadata merkezi katalogda tutulur. Satıcı dosyaları ürün ID’sine ve satış bilgilerine referans verir.

1. Depodaki veriyi aç

GitHub Pages’te açıldığında depo otomatik bulunur. Kaydetmek için mevcut admin tokenınız kullanılır.

Hazır. Veriler henüz yüklenmedi.
GitHub bağlantı ayarları

Token GitHub API’ye gönderilir ve aynı tarayıcıda yerel saklanır. Yalnızca Contents: Read and write yetkili depo tokenı kullanın.

2. Merkezi ürün kataloğu

Ürün adı ve sınıflandırmalar burada düzenlenir. İsim değişikliği aynı ID’yi kullanan tüm satıcılarda görünür.

3. Muhtemel kopyaları incele

Yazım ve kelime sırası farklarını tarar. Farklı flanker veya konsantrasyon taşıyan ürünleri birleştirme adaylarından ayrı tutar. Benzer isim tek başına aynı ürün kanıtı değildir.

Henüz tarama yapılmadı.

Satıcıya özel eşleştirme kuralları

Özel ürünleri koruyun. Bu kurallar benzerlik taramasında yanlış birleştirme adaylarını engeller.

Kural yok.

4. Değişiklikleri kaydet

İşaretlenen dosyalar tek bir GitHub commit’inde güncellenir. Commit öncesinde dosya listesi ve etkilenen kayıt sayısı gösterilir.

Kaydedilmemiş değişiklik yok.
